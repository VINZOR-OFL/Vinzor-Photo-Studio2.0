# Vinzor Photo Studio Pro (v2.0)

A high-performance, browser-based creative graphics suite and photo editor engineered with pure vanilla JavaScript, HTML5 Canvas, and modern CSS. Built with layered non-destructive editing, custom graphics tools, real-time adjustments, and automated AI utilities.

---

## 🌟 Key Features

* **Multi-Layer System:** Non-destructive raster layers, vector text layers, and parametric shapes with blend mode support (Multiply, Screen, Overlay, etc.) and opacity controls.
* **Creative Toolset:**
  * Move & Free Transform with interactive bounding boxes.
  * Variable-size Brush, Eraser, and Flood Fill Paint Bucket.
  * Vector Shape Engine (Rectangles, Rounded Rects, Circles, Stars, Lines).
  * Typography tool with real-time text properties, custom fonts, and styling.
  * Precision Color Eyedropper and Marquee Selection.
* **Document & Canvas Manipulation:** Infinite pan & zoom, crop-to-selection, canvas rotation, and layer flipping.
* **Photo Adjustments & FX:**
  * Real-time sliders for Brightness, Contrast, Hue, Saturation, and Vibrance.
  * Convolution filter presets: Gaussian Blur, Sharpen, Grayscale, Invert, Sepia, and Vignette.
* **AI Creative Studio:**
  * 1-Click Background Cutout & Foreground Isolation.
  * Magic Auto-Enhance dynamic range equalizer.
  * Generative Inpainting texture synthesizer.
* **Social Media Smart Resizer:** Instant aspect ratio presets for YouTube (16:9), Instagram (1:1 / 4:5), and TikTok/Reels (9:16).
* **State & File Management:**
  * Full Undo/Redo history stack.
  * Native project serialization (`.vinzor.json`).
  * Export to PNG, JPEG, and WebP with resolution scaling[cite: 2, 3].
